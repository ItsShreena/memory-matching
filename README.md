# 🧠 Memory Match Game

A modern and interactive memory card game built with React, TypeScript, Tailwind CSS, and shadcn/ui. Challenge your memory by matching card pairs, beating the timer, unlocking achievements, and tracking your progress.

---

## ✨ Features

### 🎮 Gameplay
- Flip cards to find matching pairs
- Random card shuffle every game
- Match all pairs to win
- Real-time move counter
- Built-in game timer
- Restart and New Game options

### 🏆 Achievements
- Speed Runner
- Perfect Memory
- Winning Streaks
- Persistent achievement tracking

### 📊 Statistics
- Games Played
- Games Won
- Win Rate
- Fastest Completion Time
- Total Moves
- Current Streak

### 🎨 Themes
Choose from multiple card packs:
- 😀 Emojis
- 🐶 Animals
- 💻 Technology
- 🚀 Space
- 👨‍💻 Programming

### ⚡ User Experience
- Smooth card flip animations
- Responsive design
- Glassmorphism-inspired UI
- Dark mode
- Confetti victory celebration
- Progress tracking

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/your-username/memory-match-game.git
```

### Navigate to Project Folder

```bash
cd memory-match-game
```

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

Open:

```bash
http://localhost:5173
```
